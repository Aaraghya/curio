# Curio 
An AI-powered curiosity engine that helps you discover unexpected connections between the things you learn.

Curio transforms topics, articles, videos, and research papers into interactive knowledge graphs and then reveals surprising relationships across your personal archive using AI and semantic search.

⚠️ **Status:** Under active development. Features, architecture, and documentation are subject to change.

## Tech Stack

- React 19
- TanStack Start
- Supabase
- Gemini 2.5 Flash
- pgvector
- Tailwind CSS
- shadcn/ui

More documentation will be added as development progresses.
